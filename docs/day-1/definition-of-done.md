# MVP Definition of Done

The MVP is done only when a fresh authorized operator can configure and execute the approved journey across isolated personas, inspect complete and tamper-evident evidence, understand transparent comparison metrics and caveats, replay without contacting the target, export independently verifiable results, and operate the service within approved security, privacy, reliability, retention, recovery, and ethical controls.

For every feature, “done” also requires:

- Automated tests at the appropriate layer.
- Versioned contracts and migration notes where applicable.
- Redacted telemetry and an operational owner.
- Documentation and runbook updates.
- Acceptance evidence linked from the traceability matrix.
- No open critical/high security finding.

Implementation alone is not completion.
